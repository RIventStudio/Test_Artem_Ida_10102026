## Текст задания

Реализация итогового проекта подразумевает под собой создание веб-сайта (презентация моей игры "STOLEN PEACE" https://github.com/RIventStudio/STOLEN-PEACE ). При создании должны быть учтены следующие требования:

### 1. Структура HTML и семантика
- Корректная структура документа (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`);
- Использование основных семантических тегов (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, заголовки `<h1>`–`<h6>`, списки, кнопки, формы);
- Работа с блочной моделью (`box-sizing: border-box`, `margin`, `padding`, `border`).

### 2. Современный дизайн
- Продуманная визуальная иерархия (заголовки, подзаголовки, смысловые акценты);
- Читаемость (отступы, контраст между текстом и фоном, удобочитаемые шрифты);
- Эстетика (единый визуальный стиль атмосферного триллера/хоррора, согласованная цветовая палитра).

### 3. Адаптивная верстка
- Использование медиа-запросов (`@media`);
- Корректное отображение на устройствах разной ширины (десктоп, планшет, мобильные);
- Минимум 2 брейкпоинта (например, `768px` и `1024px` / `480px`).

### 4. Анимации и псевдоэлементы
- Минимум 3 использования псевдоклассов и псевдоэлементов: `:hover`, `:focus`, `:nth-child`, `::before`, `::after` и др.;
- Применение CSS-анимаций и плавных переходов (`transition`, `@keyframes`).

### 5. CSS и стилизация
- Использование Flexbox / Grid (минимум 1 блок на каждом);
- Минимум 3 CSS-переменные (`--main-color`, `--font-size`, `--bg-dark` и т. п.);
- Наличие минимум одной формы (например: подписка на бета-тест, предзаказ или обратная связь);
- Стилизация форм: поля ввода, кнопки, плейсхолдеры, состояния `:focus`, базовая валидация;
- Применение позиционирования: `position: relative`, `absolute`, `fixed`, `sticky`.

### 6. Публикация
- Проект размещается на GitHub Pages, в качестве ответа прикрепляется ссылка.
